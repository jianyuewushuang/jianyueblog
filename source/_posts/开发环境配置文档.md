## node.js

### windows

从[这里](https://nodejs.org/zh-cn/download)下载msi安装包，然后安装。

### linux

```bash
# 安装node.js（需翻墙）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
# bash
source ~/.bashrc
# zsh
source ~/.zshrc
# fish（安装过oh my fish)
omf install nvm
# 安装最新 LTS 长期支持版
nvm install --lts
# 安装yarn
npm install -g yarn
# 安装pnpm
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

## c语言

### windows

1. 下载并安装MSYS2
  [下载链接](https://www.msys2.org/)（安装教程也在这里）
2. 添加环境变量
   1. 快捷键<Win> + <R>打开windows runner，输入`sysdm.cpl`打开系统属性。
   2. 在下方`系统变量`中选中`Path`，点`编辑`。
   3. 在弹出的对话框中点`新建`，粘贴路径`C:\msys64\ucrt64\bin`(电脑对应文件夹中应有`gcc.exe`、`gdb.exe`等)。
   4. 递归确定。
   5. 在终端中输入`gcc --version`验证是否添加成功。

### linux

#### Debian/Ubuntu 及衍生版

```bash
sudo apt update
sudo apt install build-essential gdb -y
```

#### Fedora/RHEL/CentOS Stream 系列

```bash
sudo dnf install gcc gdb make -y
```

#### Arch Linux 及衍生版

```bash
sudo pacman -S gcc gdb make --noconfirm
```

> 验证：`gcc --version` `gdb --version`

## rust

### linux

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
source "~/.cargo/env.nu"  # For nushell
source "$HOME/.cargo/env.tcsh"  # For tcsh
. "$HOME/.cargo/env.ps1"        # For pwsh
source "$HOME/.cargo/env.xsh"   # For xonsh
```

### windows

从[这里](https://rust-lang.org/tools/install/)下载`rustup‑init.exe`，然后运行。

或直接运行`winget install Rustlang.Rustup`。
