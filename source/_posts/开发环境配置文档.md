## c语言

### windows

#### 在UCRT64中安装

1. 下载并安装MSYS2
  [下载链接](https://www.msys2.org/)（安装教程也在这里）
2. 在打开的MSYS2 UCRT64中执行

    ```bash
    pacman -Syu
    # 在UCRT64中安装GUN编译链
    pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-make
    # 在UCRT64中安装LLVM编译链（clang是编译器，lld是链接器，lldb是调试器（vscode支持度不高，调试器仍用gdb就行））
    pacman -S mingw-w64-ucrt-x86_64-clang mingw-w64-ucrt-x86_64-lld mingw-w64-ucrt-x86_64-lldb
    ```

3. 添加环境变量
   1. 快捷键`Win`+`R`打开windows runner，输入`sysdm.cpl`打开系统属性。
   2. 点`高级`->`环境变量`，在`系统变量`中选中`Path`，点`编辑`。
   3. 在弹出的对话框中点`新建`，粘贴路径`C:\msys64\ucrt64\bin`(电脑对应文件夹中应有`gcc.exe`、`gdb.exe`等)。
   4. 递归确定。
   5. 在终端中输入`gcc --version`验证是否添加成功。

#### 在CLANG64中安装（不推荐）

> 无法使用默认的GUN编译链，需要额外配置，但报错信息更好。

1. 下载并安装MSYS2
  [下载链接](https://www.msys2.org/)
2. 在打开的MSYS2 UCRT64中执行

    ```bash
    pacman -Syu
    # 在CLANG64中安装LLVM编译链（底层全部更换报错信息更好，但无法使用gcc，需要配置clang64的环境变量）
    pacman -S mingw-w64-clang-x86_64-clang mingw-w64-clang-x86_64-gdb mingw-w64-clang-x86_64-compiler-rt
    ```

3. 添加环境变量
   1. 快捷键`Win`+`R`打开windows runner，输入`sysdm.cpl`打开系统属性。
   2. 点`高级`->`环境变量`，在`系统变量`中选中`Path`，点`编辑`。
   3. 在弹出的对话框中点`新建`，粘贴路径`C:\msys64\clang64\bin`(电脑对应文件夹中应有`clang.exe`、`clang++.exe`等)。
   4. 递归确定。
   5. 在终端中输入`clang --version`验证是否添加成功。

#### 解决中文乱码问题

1. 在设置中打开`使用 Unicode UTF-8 提供全球语言支持`，在终端中输入`chcp`，如果显示`活动代码页: 65001`说明配置成功。
2. 在`.vscode/settings.json`中写入：

    ```json
    {
    // ========== 1. 源码编码：统一 UTF-8 ==========
    "files.encoding": "utf8",
    "files.autoGuessEncoding": false, // 防止 VS Code 误判成 GBK 重新打开
    "files.eol": "\n",
    // ========== 2. 终端：保持原生，不要任何 chcp ==========
    // 系统级 UTF-8 已让 PowerShell / CMD 默认代码页为 65001
    // 关键：不设 -Command，构建命令才不会被 PowerShell 拼进脚本里
    "terminal.integrated.defaultProfile.windows": "PowerShell",
    // ========== 3. 字体：避免中文显示为空白方块 ==========
    "terminal.integrated.fontFamily": "'Cascadia Mono', 'Sarasa Mono SC', Consolas, 'Microsoft YaHei Mono', monospace",
    "editor.fontFamily": "'Cascadia Code', 'Sarasa Mono SC', Consolas, monospace",
    // ========== 4. C/C++ 插件：让 IntelliSense 与真实编译器一致 ==========
    "C_Cpp.default.compilerPath": "C:\\msys64\\clang64\\bin\\clang++.exe",
    "C_Cpp.default.cppStandard": "c++20",
    "C_Cpp.default.intelliSenseMode": "windows-clang-x64",
    }
    ```

### linux

#### Debian/Ubuntu 及衍生版

```bash
sudo apt update
sudo apt install build-essential gdb -y
```

#### Fedora/RHEL/CentOS Stream 系列

```bash
sudo dnf install gcc gdb make -y
```

#### Arch Linux 及衍生版

```bash
sudo pacman -S gcc gdb make --noconfirm
```

> 验证：`gcc --version` `gdb --version`

## rust

### linux

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
source "~/.cargo/env.nu"  # For nushell
source "$HOME/.cargo/env.tcsh"  # For tcsh
. "$HOME/.cargo/env.ps1"        # For pwsh
source "$HOME/.cargo/env.xsh"   # For xonsh
```

### windows

从[这里](https://rust-lang.org/tools/install/)下载`rustup‑init.exe`，然后运行。

或直接运行`winget install Rustlang.Rustup`。
