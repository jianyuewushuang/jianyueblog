```bash
sudo apt update && sudo apt install btrfs-progs -y
# 找到移动硬盘的设备名
lsblk
```

输出示例：

```plaintext
NAME        MAJ:MIN RM   SIZE RO TYPE  MOUNTPOINTS
sdb           8:0    0 500.1G  0 disk  
├─sda1        8:1    0   512M  0 part  /boot/efi
└─sda2        8:2    0 499.6G  0 part  /
sda           8:16   0   1.8T  0 disk  # 这是你的移动硬盘
└─sdb1        8:17   0   1.8T  0 part  /media/user/OldDrive
```

```bash
# 卸载分区
sudo umount /dev/sda*  # 卸载sdb下的所有分区
# 基础格式化（不带压缩参数）
sudo mkfs.btrfs -f -L btrfaSSD /dev/sda
# 为整个文件系统设置默认压缩属性(默认级别compress=zstd:3)
sudo btrfs property set /mnt/btrfs compression zstd
# 查看文件系统压缩属性
btrfs property get /mnt/btrfs compression
```

格式化后也可以对已有文件进行压缩：`sudo btrfs filesystem defragment -r -v -czstd /mnt/btrfs`
